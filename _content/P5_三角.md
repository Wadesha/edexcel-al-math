## 知识点

### 5.1 任意角的定义与两个定理

单位圆定义：角 $\theta$ 从正 $x$ 轴逆时针量起，终边与单位圆交点为 $(\cos\theta,\ \sin\theta)$。因此三角函数对**任意角**（不只是 $0^\circ$–$90^\circ$）都有定义，符号按象限决定。

**CAST 图**（四象限符号）：

- 第一象限（$0$–$90^\circ$）：**A**ll 全正
- 第二象限（$90$–$180^\circ$）：**S**ine 为正
- 第三象限（$180$–$270^\circ$）：**T**angent 为正
- 第四象限（$270$–$360^\circ$）：**C**osine 为正

在三角形 $ABC$ 中（边 $a,b,c$ 分别对角 $A,B,C$）：

$$\text{正弦定理：}\quad \frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}$$

$$\text{余弦定理：}\quad a^2=b^2+c^2-2bc\cos A$$

$$\text{面积：}\quad \text{Area}=\frac12 ab\sin C$$

这三个公式属于**必须背诵**的内容（考纲 Appendix 1），公式册里没有。

用法选择：

- 已知两角一边 → 正弦定理；
- 已知两边及其夹角 → 余弦定理；
- 已知三边 → 余弦定理求角；
- 已知两边及其中一边的对角（SSA）→ 正弦定理，但**注意可能有两解**（$\sin\theta=k$ 在 $0$–$180^\circ$ 有 $\theta$ 与 $180^\circ-\theta$ 两解）。

### 5.2 图像、对称性与周期性

- $y=\sin x$：周期 $360^\circ$（$2\pi$），关于原点奇对称，$\sin(180^\circ-x)=\sin x$。
- $y=\cos x$：周期 $360^\circ$，偶对称，$\cos(-x)=\cos x$，$\cos(360^\circ-x)=\cos x$。
- $y=\tan x$：周期 $180^\circ$（$\pi$），在 $90^\circ,270^\circ,\dots$ 处有渐近线。

### 5.3 两个核心恒等式

$$\tan\theta\equiv\frac{\sin\theta}{\cos\theta},\qquad \sin^2\theta+\cos^2\theta\equiv 1$$

第二条常变形为 $\sin^2\theta\equiv 1-\cos^2\theta$ 或 $\cos^2\theta\equiv 1-\sin^2\theta$，是把"混合方程"化成单一函数的关键。

### 5.4 三角方程的标准流程

1. **先化简**：用恒等式把方程变成只含一种函数（或可分解的形式）。
2. **换元**：令 $u=\sin x$（或 $\cos x$、$\tan x$），解代数方程。
3. **确定区间**：题目要求 $0\le x\le 360^\circ$ 还是 $0\le x\le 2\pi$，务必看清单位。
4. **找全解**：利用对称性与周期性写出**全部**解，再剔除区间外的。

通用技巧：

- $\sin x=k$：基准角 $\alpha=\sin^{-1}|k|$，解为 $\alpha$ 与 $180^\circ-\alpha$（按 CAST 取正值的象限），每 $360^\circ$ 重复。
- $\cos x=k$：解为 $\alpha$ 与 $360^\circ-\alpha$。
- $\tan x=k$：解为 $\alpha$ 与 $\alpha+180^\circ$。
- 倍数角：如 $\sin 2x=k$，先令 $\theta=2x$ 解出 $\theta$ 的**全部**值（区间也要翻倍：$0\le x\le 360^\circ$ 对应 $0\le \theta\le 720^\circ$），再除以 $2$。

### 常见失分点

- 计算器设在 rad 模式却按 degree 答题（或反之）。
- 忘记第二象限解，只给 $\sin^{-1}$ 的主值。
- 倍数角忘记扩大区间，导致漏解一半。

## 例题

### 例 1（余弦定理 + 面积）

三角形中 $b=7$，$c=5$，$A=60^\circ$。求边 $a$ 与三角形面积。

**解**

$$a^2=7^2+5^2-2(7)(5)\cos 60^\circ=49+25-70(0.5)=39,\qquad a=\sqrt{39}$$

$$\text{Area}=\frac12 bc\sin A=\frac12(7)(5)\sin60^\circ=\frac{35\sqrt3}{4}$$

### 例 2（SSA 两解问题）

三角形中 $a=8$，$b=10$，$A=40^\circ$。求 $B$ 的可能值。

**解**

正弦定理：$\dfrac{\sin B}{10}=\dfrac{\sin 40^\circ}{8}$，$\sin B=\dfrac{10\sin40^\circ}{8}=0.8035$。

$B=\sin^{-1}(0.8035)=53.5^\circ$ 或 $180^\circ-53.5^\circ=126.5^\circ$。

两者都使 $A+B<180^\circ$（分别是 $93.5^\circ$ 与 $166.5^\circ$），故**两解都成立**。

### 例 3（恒等式化简 + 二次方程）

解 $2\cos^2 x+\sin x=1$，$0\le x\le 360^\circ$。

**解**

用 $\cos^2x=1-\sin^2x$：$2(1-\sin^2x)+\sin x=1\ \Rightarrow\ 2\sin^2x-\sin x-1=0$。

分解为 $(2\sin x+1)(\sin x-1)=0$。

$\sin x=-\dfrac12$：$x=210^\circ,\ 330^\circ$；$\sin x=1$：$x=90^\circ$。

解集：$x=90^\circ,\ 210^\circ,\ 330^\circ$。

### 例 4（倍数角）

解 $\sin 2x=0.5$，$0\le x\le 360^\circ$。

**解**

令 $\theta=2x$，则 $0\le\theta\le 720^\circ$。$\sin\theta=0.5$ 得 $\theta=30^\circ,150^\circ,390^\circ,510^\circ$。

故 $x=15^\circ,\ 75^\circ,\ 195^\circ,\ 255^\circ$。

## 练习

**Q1.** 三角形中 $a=6$，$B=45^\circ$，$C=75^\circ$，用正弦定理求 $b$（保留 $3$ 位有效数字）。

**A1.** $A=180^\circ-45^\circ-75^\circ=60^\circ$。$\dfrac{b}{\sin45^\circ}=\dfrac{6}{\sin60^\circ}$，$b=\dfrac{6\sin45^\circ}{\sin 60^\circ}=\dfrac{6(0.7071)}{0.8660}=4.90$。

**Q2.** 三角形三边为 $5,6,7$，求最大角的余弦值。

**A2.** 最大角对边 $7$：$\cos C=\dfrac{5^2+6^2-7^2}{2(5)(6)}=\dfrac{25+36-49}{60}=\dfrac{12}{60}=0.2$。

**Q3.** 化简 $\dfrac{\sin\theta}{1+\cos\theta}+\dfrac{1+\cos\theta}{\sin\theta}$。

**A3.** 通分：$\dfrac{\sin^2\theta+(1+\cos\theta)^2}{\sin\theta(1+\cos\theta)}=\dfrac{\sin^2\theta+1+2\cos\theta+\cos^2\theta}{\sin\theta(1+\cos\theta)}=\dfrac{2+2\cos\theta}{\sin\theta(1+\cos\theta)}=\dfrac{2(1+\cos\theta)}{\sin\theta(1+\cos\theta)}=\dfrac{2}{\sin\theta}$。

**Q4.** 解 $\tan x=-\sqrt3$，$-180^\circ\le x\le 180^\circ$。

**A4.** $\tan^{-1}(\sqrt3)=60^\circ$。正切为负在第二、四象限：$x=-60^\circ,\ 120^\circ$。

**Q5.** 解 $3\sin^2x=\cos^2x$，$0\le x\le 2\pi$（弧度）。

**A5.** $3\sin^2x=1-\sin^2x\ \Rightarrow\ 4\sin^2x=1\ \Rightarrow\ \sin x=\pm\dfrac12$。$x=\dfrac{\pi}{6},\ \dfrac{5\pi}{6},\ \dfrac{7\pi}{6},\ \dfrac{11\pi}{6}$。

**Q6.** 解 $\cos\left(2x+\dfrac{\pi}{3}\right)=\dfrac12$，$0\le x\le \pi$。

**A6.** 令 $\theta=2x+\dfrac{\pi}{3}$，则 $\dfrac{\pi}{3}\le\theta\le\dfrac{7\pi}{3}$。$\cos\theta=\dfrac12$ 得 $\theta=\dfrac{\pi}{3},\ \dfrac{5\pi}{3},\ \dfrac{7\pi}{3}$。故 $2x=0,\ \dfrac{4\pi}{3},\ 2\pi$，即 $x=0,\ \dfrac{2\pi}{3},\ \pi$。
