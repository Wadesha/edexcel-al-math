# Edexcel AS Mathematics (8MA0) Study Site

Interactive study materials for Edexcel AS Level Mathematics (8MA0):
Pure (P1–P9), Statistics (S1–S5), Mechanics (M6–M8).

- `index.html` — entry / topic index
- `as_math_guide.html` — explanatory guide (17 topics, worked examples)
- `as_math_formula.html` — formula booklet + calculators
- `as_math_slides.html` — classroom slides (443 slides)
- `as_math_practice.html` — interactive practice (99 questions)

Math rendering uses a local copy of MathJax (`mathjax/tex-mml-svg.js`); no CDN required, renders offline.
Built from `_content/*.md` via the `_build_*.py` scripts.
